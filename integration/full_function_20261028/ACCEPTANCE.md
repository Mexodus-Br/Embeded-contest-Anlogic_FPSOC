核对介质 → 用户断电并隔离脉冲 → 身份/输入/STOP → 用户确认近限位起点及供电/急停 → HOME → 网页输入实测标定与边界 → 小范围 XYZ/方向 → 双坐标/示教/有限重复/取消/日志。
