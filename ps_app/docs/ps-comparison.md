# 当前 Delta Lab 与 PS 交接包的差异

核对日期：2026-10-22。本表“当前实现与证据”指封装前的旧 Delta Lab 工作树；其中旧源码路径是核对记录，不是本移交目录的运行依赖。已读取两段被引用对话；以当前工作树源码和 `ps_partner_v1_1_20261022_005289b/ps_partner_v1` 的需求为本次实现依据。旧对话中的硬件排障、部署和测试结论不当作新 PS 后端已经完成的证据。

## 结论

现有 HTML 是离线算法检查器，值得保留其三维显示、公式、时间轴及故障定位；它不是交接包要求的命令服务。不能仅改标题或将现有 `/api/runs` 接到板端。新增 PS 纯计算与协议适配先独立验证，确认共用契约后再接 HMI 和模拟执行器。

|方面|当前实现与证据|包要求与处理|
|---|---|---|
|用途|`web/app.js` 加载即计算；播放、暂停只改变回放游标|预览无副作用，运行显式开始；STOP 必须到达服务端独立停止入口|
|逆解|`src/model.cpp` double 几何约束、两个分支择连续解|直接链接 Golden float32/double64 原表达式；不替换原求解分支|
|电机顺序|方位角 `[-90,30,150]`|Golden high/low/rot 对应 `[-90,150,30]`；旧 2、3 号需要互换，不能直接复制目标数组|
|脉冲量化|相对初始角的绝对目标，`llround`|Golden 全局绝对步数，float 乘法后向零截断；按原配置，不擅自应用 `inverse` 再取负|
|时间律|五次进度 `10u³−15u⁴+6u⁵`|梯形速度，短路径三角形，各直线端点速度为零|
|时长不足|超出脉冲槽容量则全路径自动延长|显式时长不足拒绝并给原因；未指定时长才计算最短可行时间|
|起点|默认水平上臂，并把其正解当操作原点|起点可靠性必须明确；未知时可算终点 IK，路径不可执行。标原点不等于 HOME/REBASE|
|路径检查|每个采样点 double IK/FK 校验|Golden + 显式工作空间、关节、采样、步频约束；检查路径中间点，数值方案须标明 host fixture|
|PL 行为|固定 10 μs 槽，按每轴计数均匀分布至末槽|PL 共用 `Nmax=max(abs(delta))` 槽，非零轴第一槽都发脉冲。旧时序图及 0.3 s 提示线不能作为 PL 验收标准|
|运动格式|3 轴 JSON 数字、采样序号从 1 开始|4 个 signed64 目标；M4 禁用且为 0；72B MOT2、1 μs 相对 duration、会话及从 0 开始连续序号、END/CRC|
|接收与完成|HTTP 201 返回已算好的整次仿真结果|区分接收、校验、提交、运行、终态及 PL accepted/completed；不能把 HTTP 或 DMA IOC 当执行完成|
|服务与部署|Python 本机服务，x86-64 Linux 构建|最终 C++17/ARM 用户态，无 Python/Node 运行依赖；ARM 构建和实机需分别验收|
|命令管理|单次计算锁；无命令身份、期限、恢复核对|boot ID + client ID 幂等、PS 单调时钟期限、执行互斥、独立 STOP、旧启动实例拒绝|
|控制/任务|场景导入导出，任意播放回看|手动 XYZ 方向会话和坐标任务互斥；按住运动、失联停止；自主任务断网继续；版本化参数快照|
|数据来源|实际模拟边沿重建 XYZ|simulation/command/estimated/feedback 分列；遥测失败不补零；query33 是命令脉冲，query30 也不是 XYZ|
|日志|运行 JSON/CSV/VCD 文件与 ZIP|认证的结构化事件列表/过滤/详情/稳定分页/JSONL 导出，轮转与慢下载不阻塞 STOP|

旧教学仿真仍有价值：它的 double FK 可以作为后续显示候选，但须显式交换 2、3 轴并验证误差，不能直接升级为实测位置来源。脉冲事件回放需另写匹配当前 PL 契约的模型后才能称为 MOT2 执行仿真。

## 分步交付与门槛

1. 基线：原包生成定义、1272 个 Golden 向量与原始源码 oracle、MOT2、C 遥测测试。保持包内分发文件字节不变。
2. 独立库：PS-06 Golden 适配/梯形规划/全路径采样检查；PS-04 纯解码；内存 codec。无网络或设备副作用。
3. 共用契约：见 `ps-contract-proposal.md`，OPEN-01～08 不擅自宣告生产冻结。
4. 契约确认后：PS-02 命令状态机与模拟执行器 → PS-01 HMI → PS-03 参数/示教/任务 → PS-04 遥测视图 → PS-05 有界日志及完整端到端测试。
5. 交付来源/构建/测试/限制清单；项目方完成真实后端、板端工具链和实机验收。

阶段状态与实际测试结果记录在 `ps-progress.md`。主机通过不代表输出真实 STEP、不代表机械位置可靠，也不代表驱动反馈已接通。
